# Sucharitha Reddy Vakamalla - Portfolio

A futuristic, high-performance portfolio website showcasing academic research, laboratory experience, and analytical quality systems in pharmaceutical analysis.

## Profile Summary
- **Scholar**: MSc in Pharmaceutical Analysis at Queen's University Belfast, UK
- **Undergraduate**: Bachelor of Pharmacy (B.Pharmacy), JNTU (CGPA 8.2/10)
- **Specialization**: Chromatography (HPLC & GC), Formulation Quality Control, Good Laboratory Practice (GLP), and Data Integrity
- **Role**: Queen's Global Student Ambassador

## Tech Stack
- **Framework**: [Next.js](https://nextjs.org/) (App Router) + [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) + [GSAP](https://gsap.com/) + [Lenis](https://lenis.darkroom.engineering/) Smooth Scroll
- **UI & Icons**: [Lucide React](https://lucide.dev/) + [CMDK](https://cmdk.paco.me/)

## Getting Started

First, install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build

```bash
npm run build
npm run start
```
